# Contributing

Thanks for considering a contribution to `retrospective`. This is a small, single-skill repo.

## Before you start

- **The skill produced a bad review?** Open an issue with what you asked for, which focus it ran (full, `--focus spend`, or `--focus wiring`), and where it went wrong — a session filed under the wrong shape, a token claim that looked fabricated, a waste it missed or invented, a wire-in that named a file that does not run. This is the highest-value kind of report here.
- **Proposing a change to the flow?** Open an issue describing the gap. The shape → context → wiring order and the honesty rules are deliberate; if you're proposing to change them, explain why the existing structure doesn't already cover your case.
- **License or copyright holder:** don't change without asking first.

## Making a change

1. Fork and branch from `main`.
2. Keep edits inside `skills/retrospective/`.
3. Preserve the honesty rules: current session only, never open an on-disk log, no fabricated counts or quotes, never block on a denied read or write. Any change to the method should keep those properties intact.
4. Keep the six shape names, the five economy-rule names, and the score key identical between `SKILL.md` and `references/` — the review cites them by name.

## Questions

Open an issue. There's no separate chat or forum for this project.
